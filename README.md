# 赛博朋克 2077 入侵协议

由 [Cyberpunk_CodeMatrix_decipher](https://github.com/zlmturnout/Cyberpunk_CodeMatrix_decipher) 迭代而来。原项目用手填的代码矩阵穷举路线。这一版直接读截图，并标出能上传最多序列的走法。

## 使用

双击 `启动.bat`，或在这个目录执行：

```bat
python app.py
```

打开截图，或先复制截图再按 Ctrl+V。左侧会标出 1、2、3…，右侧可以改认错的格子和缓冲格数。

依赖：Python 3、`numpy`、`pillow`。

```bat
python -m pip install -r requirements.txt
```
